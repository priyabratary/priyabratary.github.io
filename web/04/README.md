# NOVA Futuristic Landing Page

A lightweight, responsive single-page website built with semantic HTML, CSS, and vanilla JavaScript. All visual artwork is generated with CSS and inline SVG—there are no image or JavaScript framework dependencies.

## Deploy to HostGator

1. Open HostGator cPanel and launch **File Manager**.
2. Open the `public_html` directory for the target domain.
3. Upload the contents of this folder, keeping the `assets` directory intact.
4. Confirm that `index.html`, `style.css`, and `script.js` sit directly inside `public_html`.

## Customize

- Replace the `NOVA` wordmark and placeholder mark in `index.html`.
- Update the headline, tagline, metadata, and social links in `index.html`.
- Replace `assets/favicon.svg` with your own favicon if desired.
- Connect the form handler in `script.js` to your chosen backend or HostGator mail script.

## Files

- `index.html` — semantic page structure and SEO metadata
- `style.css` — responsive styling, orbital visual, and motion
- `script.js` — reveal effects, parallax, navigation state, and form feedback
- `assets/favicon.svg` — lightweight placeholder favicon

No build step is required.
